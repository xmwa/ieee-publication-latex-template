\section{Additional Derivations}
\label{sec:s-derivations}

This document collects material that did not fit in the main paper. Start with the full derivation of a result stated there, for example
\begin{equation}
  \hat{\theta} = \arg\min_{\theta}\; \sum_{i=1}^{N} \bigl\| y_i - f_\theta(x_i) \bigr\|_2^2 ,
  \label{eq:s-estimator}
\end{equation}
which follows the notation of~\cite{shell2015ieeetran}. Equation~\eqref{eq:s-estimator} is numbered (S1), so the main paper can cite it without ambiguity.
